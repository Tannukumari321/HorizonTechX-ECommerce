# HorizonTechX E-Commerce Website

## Project Overview
This is a simple E-Commerce website developed using HTML, CSS, and JavaScript. The project demonstrates the basic structure and functionality of an online shopping website.

## Features
- Home Page
- Navigation Bar
- Product Section
- Responsive Layout
- Interactive Button using JavaScript
- Clean and Simple User Interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
```
HorizonTechX-ECommerce/
│── index.html
│── style.css
│── script.js
│── README.md
```

## How to Run
1. Download or clone the repository.
2. Open `index.html` in any web browser.
3. Explore the website.
